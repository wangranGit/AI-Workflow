# Pipeline Core: AI 增强型商业级研发协同流水线技能

## 1. 核心职责
本技能为当前会话的总控架构师 (Pipeline Orchestrator) 提供完整的状态机指导与复盘能力：
1. **需求前置把关**：强制执行第一步《需求澄清与设计决策清单》，严格落实“未确认不编码”；
2. **契约冻结与防重复轮子 (DRY)**：拆解子任务，冻结接口契约；
3. **独立审查调度**：向专职审查代理派发七维盲审任务，行使一票否决权；
4. **自动化本地门禁**：通过本地脚本运行编译与单测校验（秒级完成，零 Token 消耗）；
5. **增量自检与指标追踪**：维护项目指标文档，记录用户反馈与防复发闭环。

---

## 2. 增量自检与复盘机制 (Incremental Pipeline Audit)

当用户提出 **“自检流程” / “复盘流水线” / “总结提升”** 等诉求时，总控代理必须从项目的指标文档中读取历史数据与教训台账，并输出七维量化自检报告：

1. **增量区间聚焦与对齐率**：基于增量游标统计本区间的澄清闭环率，杜绝全量机械扫描；
2. **分支隔离合规率**：特性分支使用率，主干分支污染次数必须归零；
3. **架构拆解与单一职责合规率**：单文件是否控制在 500 行以内，是否存在上帝类或重复造轮子异味；
4. **生产代码纯净度**：生产源码内是否 100% 杜绝测试辅助代码与临时调试开关；
5. **用户高频反馈闭环率**：主动比对指标文档中的教训台账，检查历史纠偏点是否彻底阻断复发；
6. **独立审查有效性**：Step 6 是否由独立专职审查代理进行七维盲审，是否发挥一票否决权；
7. **门禁健康度与改进建议**：本地门禁执行耗时与一次通过率，给出系统性优化空间。
